# Data preparation

Dataset files are not included. Obtain each dataset and its annotations from its provider and follow their terms. Evaluation reads data below `data/`; see `src/data.py` and `modal_eval.py` for expected layouts.

- **Fashion-IQ:** annotations: [XiaoxiaoGuo/fashion-iq](https://github.com/XiaoxiaoGuo/fashion-iq); image source noted by the original guide: [postBG/CosMo.pytorch](https://github.com/postBG/CosMo.pytorch). Modal expects `data/fashion-iq/`.
- **COCO:** obtain `val2017` and `annotations/instances_val2017.json`. From repository root run `python data/coco/prepare_data.py` to prepare evaluation inputs.
- **CIRR:** obtain images and annotations via [CIRR project instructions](https://github.com/Cuberick-Orion/CIRR). Modal expects `data/CIRR/` with captions, image_splits, and the image tree referenced in `modal_eval.py`.
- **ImageNet-R / ImageNet Real:** obtain ImageNet-R from [hendrycks/imagenet-r](https://github.com/hendrycks/imagenet-r) and ImageNet validation images through applicable access terms. Image trees are not included; the query and target lists are included under `data/imgnet/`.

The upstream layout notes follow for reference.
