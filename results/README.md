# Results index

The artifacts in this directory were copied unchanged from the local experiment repository. Logs and parameter snapshots may retain original environment-specific paths. CIRR Test1 has no saved log or params in the source repository; its artifacts are limited to predictions and report files.

- `fashion_iq/logs/`: Dress, Shirt, and Toptee logs.
- `fashion_iq/params/`: corresponding three parameter snapshots.
- `coco/logs/` and `coco/params/`: COCO evaluation log and parameters.
- `cirr/validation/logs/` and `cirr/validation/params/`: validation log and parameters.
- `cirr/cirr_test1/predictions/`: four prediction JSONs for composed, image, text, and mixture methods.
- `cirr/cirr_test1/report/`: summary CSV and four result images.
- `imagenet_r/logs/` and `imagenet_r/params/`: ImageNet-R log and parameters.

CIRR Test1 predictions/report files are provided as saved artifacts. No Test1 execution log, parameter file, or additional scoring command is claimed here. See `../reports/GITHUB_REPRODUCTION_AUDIT.md` for provenance limitations.
